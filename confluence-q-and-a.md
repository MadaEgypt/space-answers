# Q&A in Confluence: the options

People search for a "Confluence Q&A macro" or a "Q&A template" and find that Confluence Cloud doesn't include a questions-and-answers feature of its own. Teams put one together from the parts below. What matters in the end is the same for all of them: **can the next person who has the same question find the answer by searching?**

## Page comments

Someone asks in a comment on the page the question is about, and someone replies.

- **Good:** no setup, and the question sits next to the content it's about.
- **Bad:** there's no "accepted" answer, long threads are hard to read, and search results show the page title, not the question. Questions that aren't about one page have nowhere to go.

## An FAQ page

The team collects common questions on a page, or one page per question.

- **Good:** answers are written to last and are easy to link to.
- **Bad:** someone has to copy each question in from wherever it was asked, so it goes stale. [How to build one that lasts](how-to-create-faq-page-confluence.md).

## Rovo (Atlassian's AI)

Where your plan includes it, people can ask Rovo and get an answer drawn from your existing pages.

- **Good:** answers come instantly, from everything already written.
- **Bad:** it can only use what someone wrote down. When the answer isn't in Confluence yet, nobody is asked, and nothing is captured for next time.

## A Q&A app

An app from the Atlassian Marketplace gives Confluence a real place to ask, answer and accept answers.

- **Atlassian's Questions for Confluence** keeps one site-wide Q&A area with topics and voting. Users in its reviews report that search finds question titles but not words that appear only in answers. [How it compares, and how to switch](switch-from-questions-for-confluence.md).
- **[Space Answers for Confluence](https://rojymart.com/go/docs/qa-article)** (we make it) puts a Questions page in each space. A space admin picks which groups may ask and which may answer; the asker accepts the answer that worked, and it is shown first. Every question has a normal Confluence page with all its answers, so Confluence search finds any word in an answer. Data stays in your Confluence site (it runs on Atlassian's Forge platform).

## Which one to use

| If your team… | Use |
|---|---|
| asks a few questions, each about a specific page | page comments |
| has 10–20 questions that rarely change | an FAQ page |
| has most answers written down already | Rovo, if your plan has it |
| keeps asking new questions in chat and losing the answers | a Q&A app, so questions are asked and answered where they can be found |

Most teams end up with two: an FAQ page or Rovo for what is already known, and a Q&A place for what isn't yet.
